# SSB Code of Ethics for Artificial Intelligence Systems

This repository contains the SmallSmartSandbox Code of Ethics for AI systems,
their operators, tools, and evaluation infrastructure.

The Code defines principles and behavioral requirements for safety, human
responsibility, authorization, privacy, transparency, sandbox security, and
research. It also includes technical requirements for isolation, monitoring,
shutdown, safe failure, and compliance testing.
